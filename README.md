# Mellow Minutes

하늘색 아날로그 타이머의 감성을 담은 React 뽀모도로 시계입니다.

## 기능

- 1분부터 60분까지 숫자로 집중 시간 설정
- 원형 다이얼을 마우스 또는 터치로 드래그해 설정
- 남은 시간에 따라 줄어드는 컬러 그래프
- 시작, 일시정지, 재개, 꾹 눌러서 초기화(오조작 방지)
- **자동 뽀모도로 사이클**(설정에서 켜고 끌 수 있음): 집중이 끝나면 짧은 휴식(5분)으로, 4회마다 긴 휴식(15분)으로 자동 전환. 꺼두면 집중 타이머만 반복
- 오늘 완료한 집중 세션 수 표시 (일반 모드 헤더 · Simple 모드 상단 배지 양쪽에서 확인 가능)
- 세션 종료 시 소리 + macOS 시스템 알림(창이 숨겨져 있어도 확인 가능)
- 메뉴바 아이콘에 남은 시간 실시간 표시
- 전역 단축키(⌘⇧M)로 다른 앱에서도 시작/일시정지
- 집중 시간 종료 시 불빛·컨페티 알림 효과
- 모바일과 키보드 조작 지원
- macOS 메뉴바 아이콘과 별도 타이머 창
- 항상 위에 표시, 자유로운 창 크기 조절(고정 비율) 및 창 위치/크기 복원
- macOS 시스템 라이트·다크 모드 자동 적용

## macOS 앱 실행

macOS 개발 도구와 Rust를 설치한 후 실행합니다.

```bash
npm run mac:dev
```

배포용 `.app`과 `.dmg` 생성:

```bash
npm run mac:build
```

창을 닫으면 앱은 메뉴바에서 계속 실행됩니다. 완전히 종료하려면 메뉴바의
`Mellow Minutes 종료`를 선택하세요.

`main` 브랜치에 변경 사항이 올라오면 GitHub Pages로 자동 배포됩니다.
